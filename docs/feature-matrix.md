# Feature completion matrix (F01–F40)

This file tracks the status of every feature, F01 to F40. Requirements are defined in [project-documentation.md](project-documentation.md) §6. Update the matrix in the same change that alters a feature's status.

Status legend:

- **Implemented**: code, host tests and console UI exist, and `pnpm check` passes.
- **Bounded**: implemented, with the documented limits listed under "Known limits".
- **Live**: the feature has run against the real external service (Twitch, OpenAI, OBS, Firebot, Streamer.bot). No feature has yet been validated live end to end. Release depends on live validation (see the bottom of this file).

Last integration: branch `feat/close-feature-gaps`, 2026-11-02. `pnpm check` result: 106 files / 1102 tests. `build`, `check:bundles`, `smoke` and `format:check` also pass.
