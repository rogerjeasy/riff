# Feature completion matrix (F01–F40)

This file tracks the status of every feature, F01 to F40. Requirements are defined in [project-documentation.md](project-documentation.md) §6. Update the matrix in the same change that alters a feature's status.

Status legend:

- **Implemented**: code, host tests and console UI exist, and `pnpm check` passes.
- **Bounded**: implemented, with the documented limits listed in the row.
- **Partial**: part of the requirement in project-documentation.md is missing; the row names what.
- **Live**: whether the feature has run against the real external service in production (Twitch, OpenAI, OBS, Firebot, Streamer.bot). _Blocked_ means Twitch eligibility prevented it on the test channel.

Last integration: `main`, 2026-11-02. Status verified by an independent audit of project-documentation.md against the code (F01–F40 and acceptance scenarios A1–A36). `pnpm check`: 129 files / 1289 tests.

## Open design decisions

None. The trigger model is one discriminated `trigger.kind` (`chat.command`, `points.redeem`, `twitch.event`), and automatic raider shoutouts use the host-owned raid rule (see AGENTS.md, F21/F23).
